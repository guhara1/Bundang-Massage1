# 바로 GO — 분당 출장마사지·홈타이 안내 사이트

경기도 성남시 분당구 전지역 방문 관리(출장마사지·홈타이) 안내용 정적 사이트입니다.

- **상호:** 바로 GO
- **전화예약:** 0508-202-4719 (연중무휴 24시간 상담)

## 구조

- 정적 HTML 사이트 — 어느 호스팅(GitHub Pages, Netlify, 일반 웹서버)에서든 그대로 서빙 가능
- `build.py` + `content/` 패키지에서 페이지를 생성하는 빌드 방식
- URL은 메인도메인 루트 기준의 짧고 깔끔한 구조 (깊은 경로 중첩 없음)

```
build.py            # 빌드 스크립트 (레이아웃·글자수/디스크립션 검사·스키마 주입·sitemap)
content/
  site.py           # 상호·전화·BASE_URL·텔레그램·메뉴(NAV)
  pricing.py        # 공통 예약 기준 블록 (글자수 측정 제외)
  main.py           # 메인 페이지 (+ FAQPage JSON-LD, 히어로)
  areas.py          # 지역별: 분당 허브 + 대표 동 12개
  stations.py       # 역세권: 허브 + 역 8개 + 인접 생활권 3개
  zones.py          # 생활권: 허브 + 생활권 12개
  info.py           # 예약 안내·이용 전 확인사항·홈타이 가이드·고객센터·사이트 소개·약관
assets/             # CSS(프리미엄 팔레트), 모바일 내비 JS, 파비콘/OG 이미지
```

## 빌드

```bash
python3 build.py
```

빌드 시 페이지별 본문 글자수, 디스크립션 길이, robots 상태가 출력됩니다.

## SEO 운영 원칙 (빌드에 강제됨)

- 본문 **2,000자 미만 페이지는 자동 `noindex`** 처리되고 sitemap에서 제외
- **메타 디스크립션 80자 초과 시 경고** 출력
- 모든 페이지에 **WebPage·BreadcrumbList·Organization·ImageObject** 구조화 데이터 자동 주입
  (방문형 서비스로 실제 사업장 주소가 없어 `LocalBusiness`는 사용하지 않음)
- 메인은 추가로 **FAQPage** JSON-LD 적용
- 대표동은 12개만 (정자·수내·서현·이매·야탑·판교·삼평·백현·금곡·구미·운중·분당동) — 숫자 행정동 페이지 없음
- 역은 역명당 1개 — 환승역도 URL 하나, 출구별 페이지 없음
- 동천·보정·모란역은 분당 인접 생활권 안내로만 처리 (타 행정구 성격)
- 메뉴명·URL에 "출장마사지" 미반복, 본문 첫 문단·제목에만 자연스럽게 포함
- 페이지마다 고유 본문 (지역명만 바꾼 복붙 없음), 도어웨이/조합 페이지 없음

## 디자인

- **프리미엄 팔레트**: 옵시디언 베이스 + 샴페인 골드 + 오렌지 액센트 (디자인 토큰 교체)
- 본문 폰트 **Pretendard**, 헤딩 Noto Serif KR
- 컴포넌트 오버레이(섹션 글로스·골드 라인) 적용
- 푸터 **오렌지 텔레그램 버튼**: 웹사이트 제작문의 / 제휴문의

## 배포 전 해야 할 일

1. `content/site.py`의 `BASE_URL`을 실제 도메인으로 변경
2. 필요 시 `TELEGRAM_BUILD` / `TELEGRAM_PARTNER` 링크 확인
3. `python3 build.py` 재실행 (canonical·sitemap·robots·스키마에 반영)
4. Google Search Console에 `sitemap.xml` 제출
